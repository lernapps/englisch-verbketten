# Skizzen der Seiten (Schritte, was die Kinder sehen)

Jede Seite: einstieg (Szene-SVG + erste Aufgabe + „Das kannst du danach“) → neu (Verbkette-SVG, Merke-Kasten, Poster-Tabelle) → uebung (4–6 Übungen) → anwenden → weiter.

- can-must: Szene Schilder im Flur → Sortieraufgabe → Kette ohne Kupplung (verbkette-ohne-kupplung.svg) → Poster can/can't/must/mustn't/needn't → Übungen → Schulregeln schreiben.
- modalverben-could-might-should: Szene Wochenende planen → Zuordnen → Skala (verbkette-skala.svg) → Poster erweitert → Übungen → Rat an Peter.
- would-like: Szene Kiosk → höflich oder direkt → Kette mit to (verbkette-kupplung-to.svg) → Poster I'd like → Übungen → Bestellung; Rückblick.
